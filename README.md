# OpenCV Fundamentals

A practical repository covering essential computer vision tasks and image processing techniques using OpenCV. 

## Topics Covered

This repository includes scripts and examples for the following operations:

- **Opening Images and Videos**: Reading and displaying media files.
- **Accessing the Camera**: Real-time video capture from a webcam.
- **Image Filters**: Applying Grayscale, Blur, and Canny Edge Detection.
- **Transformations**: Resizing and cropping images.
- **Drawing and Text**: Drawing shapes and adding text overlays to images.
- **Image Blending**: Merging and blending multiple images.
- **Color Detection**: Identifying and isolating specific colors.
- **Shape Detection**: Recognizing basic geometric shapes.
- **Face Detection**: Basic face detection algorithms.
- **Saving Images**: Writing processed images to disk.
- **Object Detection**: Identifying various objects within a frame.

## Prerequisites
- Python 3.x
- OpenCV (`pip install opencv-python`)
- NumPy (`pip install numpy`)
